# CrateTrack NG

Reusable produce crate rental ledger. Track crates by QR code from farm to market.

## Setup
```bash
flutter pub get
dart run build_runner build --delete-conflicting-outputs
flutter run
```

## Architecture
Clean Architecture + BLoC state management. Dark theme, advanced UI, Android & iOS.
